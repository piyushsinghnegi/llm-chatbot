# LLMOps – Simple chatbot

## Overview
LLMOps uses a large language model (LLM) to perform **simple chatbot**.  

## Setup
1. Clone the repo:
```bash
git clone <repo-url>
cd llmops
```
2. Install dependencies:
```bash
pip install -r requirements.txt
```
3. Docker compose:
```bash
docker compose up --build
```
4. Run infrence:
Go to http://localhost:8080/docs
